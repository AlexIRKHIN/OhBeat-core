# Срез 2. Итоги

Дата: 02.11.2026. План — [slice-2-plan.md](slice-2-plan.md).

## Что сделано

- **Core API:** публичный каталог `GET /v1/beats` (фильтры, «сначала новые», курсорная пагинация) и страница продюсера `GET /v1/producers/{id}` с теми же фильтрами. Код — `backend/app/catalog/browse.py`.
- **Плеер** — один на всё приложение (`frontend/src/player/`): `preload="none"`, при переключении `pause()` → `removeAttribute('src')` → `load()`, шкала перемотки, задержка старта звука в консоли.
- **Экраны:**
  - каталог на главной: фильтры в адресе страницы, «Показать ещё», все состояния;
  - страница бита: лицензии с ценами и составом файлов;
  - страница продюсера с витриной;
  - в «Моих битах» — кнопка «Публичная страница», превью через общий плеер.
- **Демо-набор:** `docker compose exec api python -m seeds.demo_beats` — 12 битов через настоящий путь (API → MinIO → Worker). Повторный запуск ничего не дублирует.

## Как проверить руками

1. `docker compose up -d`; демо-набор (если ещё не запускали): `docker compose exec api python -m seeds.demo_beats`.
2. Откройте <http://localhost:5173> **без входа** (или в окне инкогнито): каталог доступен гостю.
3. DevTools → Network → тип **Media**: до Play пусто; Play → `206`. Переключите бит: появится запрос второго превью.
4. **Как увидеть перемотку по сети:** во вкладке Network поставьте скорость **Slow 4G**, включите «Буду Скучать» и сразу кликните ближе к концу шкалы. Появится новый запрос с другим `Range` и ответом `206`, а прежний станет «(canceled)». Без ограничения скорости MinIO отдаёт файл целиком за доли секунды, и перематывать можно без сети.
5. Консоль браузера: строки `[OhBeat] first sound in … ms`.
6. Фильтры, «Сбросить», страница бита, страница продюсера (ссылка из карточки или «Публичная страница» в «Моих битах»).

## Что важно знать

- **«Показать ещё» в браузере не видна**: в каталоге 14 битов, а страница — 20. Пагинацию проверяют автотесты на `limit=2`. Увидеть кнопку руками можно, если запустить демо-набор с другими названиями или загрузить ещё биты.
- **Перемотка без сети на локальной машине** — нормальное поведение браузера: всё уже скачано. Range-запросы при перемотке видны на медленном соединении (п. 4).
- **Исправлено по ходу:** значки ▶/❚❚ были текстом и на Windows превращались в цветные эмодзи — заменены на SVG.
- **Новые GAP:** GAP-58…GAP-61.
