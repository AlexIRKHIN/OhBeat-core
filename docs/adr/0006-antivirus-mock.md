# ADR 0006. Антивирус для ZIP: мок

Дата: 31.10.2026. Статус: принято (решение аналитика).

## Контекст

FR-9 требует проверить ZIP со стемами на вирусы. Конкретное средство документация не задаёт.

## Варианты

- **ClamAV в docker.** Настоящая проверка, но контейнер занимает 1–2 ГБ памяти, а первая загрузка баз идёт несколько минут.
- **Мок.** Лёгкий, но проверка не настоящая.

## Решение

Мок за интерфейсом `AntivirusScanner` внутри Media Worker. Находит «вирус» по тестовой сигнатуре EICAR в любом файле архива. По настройке изображает недоступность сканера: это временная ошибка, которая проверяет повторы и DLQ.

## Последствия

- Отклонение по вирусу проверяется файлом из `samples/` с сигнатурой EICAR.
- Настоящий сканер можно подключить позже, реализовав тот же интерфейс.
