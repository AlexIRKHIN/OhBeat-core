# ADR 0006. Антивирус для ZIP: мок

Дата: 31.10.2026. Статус: принято (решение аналитика).

## Контекст

FR-9 требует проверить ZIP со стемами на вирусы. Конкретное средство документация не задаёт.

## Варианты

- **ClamAV в docker.** Настоящая проверка, но контейнер занимает 1–2 ГБ памяти, а первая загрузка баз идёт несколько минут.
- **Мок.** Лёгкий, но проверка не настоящая.

## Решение

Мок `MockAntivirus` внутри Media Worker (`worker/worker/antivirus.py`). Находит «вирус» по тестовой сигнатуре EICAR или по собственной тестовой метке OhBeat в любом файле архива. Образцы файлов на компьютере разработчика используют собственную метку: настоящий антивирус Windows поместил бы файл с EICAR в карантин. По настройке изображает недоступность сканера: это временная ошибка, которая проверяет повторы и DLQ.

## Последствия

- Отклонение по вирусу проверяется файлом `samples/bad_stems_virus.zip` (собственная метка) и автотестом с настоящей строкой EICAR, которая собирается в памяти внутри Linux-контейнера.
- Настоящий сканер можно подключить позже, реализовав тот же интерфейс.
