# ADR 0004. Генерация PDF: WeasyPrint

Дата: 31.10.2026. Статус: принято.

## Контекст

FR-26 требует PDF лицензионного договора с данными сторон, условиями лицензии и штампом ПЭП (RFC §5); хэш файла хранится в `contracts.pdf_sha256`.

## Варианты

- **WeasyPrint** — HTML и CSS превращаются в PDF. Шаблон договора остаётся читаемым текстом. Минус: нужны системные библиотеки в docker-образе.
- **ReportLab** — PDF «рисуется» кодом. Нет зависимостей, но любая правка текста договора — правка программы.

## Решение

WeasyPrint. Договор — HTML-шаблон (Jinja2), шрифт с кириллицей встроен в образ. Тот же шаблон рендерится в текст проекта для `draft_sha256` (GAP-9), поэтому проект и итоговый PDF строятся из одних данных.

## Последствия

- Шаблон договора можно читать и править без знания Python.
- PDF детерминирован при одинаковых данных, кроме метаданных времени создания: их фиксируем, чтобы повторная генерация давала тот же файл (GAP-43).
