# ADR 0003. Фронтенд: React, TypeScript, Vite, Tailwind CSS

Дата: 31.10.2026. Статус: принято.

## Контекст

Архитектура требует SPA с интерфейсами Артиста, Продюсера и Администратора, клиентскую валидацию по UI-спецификации, загрузку файлов в S3 с прогрессом, два языка (NFR-26) и адаптивность от 320 px (NFR-9, NFR-21). Браузеры — Chrome 100+, Safari 15+, Firefox 100+.

## Варианты

- **React + TypeScript + Vite.** Самая большая экосистема и самый востребованный навык. Минус: JSX поначалу непривычен.
- **Vue 3 + TypeScript + Vite.** Шаблоны ближе к HTML, но экосистема и примеры под наши задачи беднее.

## Решение

React 18, TypeScript, Vite. Формы — React Hook Form + Zod (одна схема правил на форму; кнопка отправки неактивна, пока схема не пройдена — FR-3, NFR-11). Запросы к API — TanStack Query. Переводы — react-i18next. Вёрстка — Tailwind CSS. Загрузка в S3 — `XMLHttpRequest` (у него есть события прогресса, у `fetch` — нет).

## Последствия

- Фронтенд собирается и запускается в docker; Node.js на машине не нужен.
- Сборка нацелена на Safari 15 (`build.target`), чтобы не использовать неподдерживаемый синтаксис.
