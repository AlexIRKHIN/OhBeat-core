# ADR 0009. Оформление интерфейса: тема Neptunian

Дата: 31.10.2026. Статус: принято (решение аналитика).

## Контекст

Документация задаёт экранные формы, валидацию и адаптивность (NFR-9, NFR-21), но не визуальный стиль. Аналитик выбрал цвета темы Neptunian: тёмная, в духе интерфейсов музыкальных программ — аудитории OhBeat она близка.

## Решение

Только тёмная тема. Цвета заданы смысловыми именами в `frontend/tailwind.config.js`, компоненты используют только эти имена:

| Имя | Цвет | Где |
| --- | --- | --- |
| `nep` | `#1b1c1e` | фон страницы |
| `panel` / `panel-2` | `#222326` / `#18191b` | карточки / поля ввода и «колодцы» |
| `line` | `#303236` | рамки и разделители |
| `ink` / `soft` / `muted` | `#d9eef7` / `#a9c3cf` / `#7a8f99` | основной, вторичный текст, подсказки |
| `cyan` | `#78d2f2` | заголовки, подписи полей, ссылки (как «Adjustments», «Hue») |
| `accent` / `accent-deep` / `accent-light` | `#3eaaea` / `#2a72aa` / `#4fbfe1` | кнопки и фокус (образцы Mute, Highlight, Selection) |
| `orange` | `#f2a43a` | второй акцент: прогресс загрузки (кольца ручек) |
| `danger` | `#f06a72` | ошибки |

- Основная кнопка — синий градиент, как активная кнопка «A».
- Второстепенная кнопка — тёмная плашка с голубым текстом, как «Reset» и «Save preset…».
- Родные элементы браузера (выпадающие списки, полосы прокрутки) переведены в тёмную схему (`color-scheme: dark`), а чекбоксы и радиокнопки — в синий акцент (`accent-color`).

## Последствия

- Сменить или донастроить тему можно в одном файле.
- Шрифт — системный: внешние шрифты не подключаем, чтобы интерфейс не зависел от сторонних серверов.
- Светлой темы нет. Документация её не требует; если понадобится, её можно добавить через те же смысловые цвета.
